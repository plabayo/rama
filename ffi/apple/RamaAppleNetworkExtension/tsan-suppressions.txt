# ThreadSanitizer suppressions for the RamaAppleNetworkExtension Swift test suite.
#
# Run via:  just run-tproxy-ffi-e2e-swift-tsan
#   (from ffi/apple/examples/transparent_proxy; or set
#    TSAN_OPTIONS=suppressions=<this file> for a raw `swift test --sanitize=thread …`).
#
# WHY THIS EXISTS — read before adding/removing
# ---------------------------------------------
# Production confines mutable per-flow state to the flow's serial `flowQueue`.
# A few remaining tests poll queue-confined state from the test thread while an
# asynchronous lifecycle callback may update it. Suppress only stack frames from
# the test target; a production/production race has no `Tests` frame and remains
# visible. Prefer routing new test access through `ctx.flowQueue.sync` instead of
# expanding this file.
race:Tests
