# QUIC specifications

Unmodified RFC Editor text, retrieved 2026-09-14:

- [RFC 8999](https://www.rfc-editor.org/rfc/rfc8999): version-independent QUIC properties.
- [RFC 9000](https://www.rfc-editor.org/rfc/rfc9000): QUIC transport.
- [RFC 9001](https://www.rfc-editor.org/rfc/rfc9001): TLS integration and packet protection.
- [RFC 9002](https://www.rfc-editor.org/rfc/rfc9002): loss detection and congestion control.
- [RFC 8899](https://www.rfc-editor.org/rfc/rfc8899): datagram packetization-layer MTU discovery.
- [RFC 9221](https://www.rfc-editor.org/rfc/rfc9221): unreliable datagrams.

TLS 1.3's [RFC 8446](../../rama-net/specifications/tls/rfc8446.txt) is shared with the TLS implementations. Each RFC retains its copyright and license notices.
