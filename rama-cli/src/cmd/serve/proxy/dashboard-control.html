Local response rules run first. Interception rules then choose “Require approval” or “Forward automatically”. Empty matcher fields match everything; host and path support *. A leading dot includes a host’s subdomains. Protocol names are extensible (for example http, https, ws, wss).

Timeouts and queue overflow return an error or close the WebSocket; they never forward unapproved traffic. Pending messages survive browser refreshes.

Up to 4,096 recent hosts are retained; 100 matching rows are shown. Counts describe observed connections, not requests. Adding a host to MITM scope affects new connections. Explicit CLI restrictions still apply.
